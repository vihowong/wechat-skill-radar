## 导语
三句话讲清：它是什么、谁需要它、读完你能拿到什么（一套从零跑通的步骤）。
（导语会渲染成浅灰圆角卡片。）

## 一、它是什么
一句话定位，补一句"它替你做哪件事"。
官方公布的关键数字照着写，标明出处与日期，例如「据官方文档，单次可处理 100 万字（2026-10-10 查）」。

![官方首页界面](配图/配图1_官方界面.png)
图片：图源 项目 README · github.com/owner/repo

## 二、装它
照抄官方命令，写清前提（Node / Python / 密钥 / 平台账号），并给出上手门槛分级。

**装它**：`npx skills add owner/repo`

README 里写明要先装 Node 20 以上；没有 Node 的人先花两分钟装一下。这里给一句"装完大概多久、会看到什么"。

## 三、跑通第一步
照抄官方的最小示例，说清输入什么、得到什么。这一步要让完全新手也能照着做完。

## 四、常用操作
挑 3–5 条最常用的命令或用法，每条配一句"什么时候用"。字段名与顺序全篇保持一致。

## 五、它会卡在哪
两条来源分开写：官方文档明确写出的限制（照抄），以及 issue 区反复出现的报错（写明"有人在 issue 里提到"）。

## 六、谁该用，什么人不用装
把不适用的读者挡在外面，比再夸一遍有用。

## 结语
先做哪一步 + 一句边界提醒（第三方指令要先看权限与数据）。
