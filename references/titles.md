# 标题：一次给 6–8 个候选，而不是两个

公众号的打开率主要由标题和封面第一行决定。所以每期不是"起一个标题"，而是给一组候选，让用户自己挑。

## 一、硬要求

- 每期在发布稿元信息里给 **6–8 条标题候选**，其中 1 条「推荐标题」、3–5 条「备选标题」。
- 推荐标题 **≤20 个汉字**（列表页不折行、不被截断）；备选尽量 ≤22 字。
- 候选覆盖 **至少 4 种钩子类型**（见下表），不要 6 条都是同一句式的换词。
- 标题里不出现：震惊、必看、宝藏、神器、YYDS、绝了、速看、限时、月入、稳赚、免费领、禁止错过。
- 标题里也不出现极限词与违规词：最强、第一、唯一、顶级、绝对、100%、国家级、史上最强、闭眼入、抄底；圈内黑话（封神、炸裂、爆杀）同样算标题党。完整清单见 `compliance.md`。
- 不承诺结果、不夸大收益；数字必须与正文对得上（写"10 个"就必须真的是 10 个）。
- 手册与解读类的标题必须带一个具体事实（官方公布的数字、明确的门槛、版本时间点），空泛的"某某深度解析"不算标题。
- 不拿第三方账号名或平台名当卖点。

## 二、钩子类型表（每期至少挑 4 种）

| 类型 | 抓什么 | 例子骨架 |
| --- | --- | --- |
| 数字清单 | 数量 + 品类 | 「10 个…技能，附安装命令」 |
| 身份认同 | 直接点名读者 | 「给做视频的人挑技能」 |
| 场景痛点 | 读者此刻正卡住的事 | 「素材一堆剪不动？」 |
| 反常识 | 与直觉相反的事实 | 「星标最高的，竟然不是技能」 |
| 结果承诺 | 明说交付物 | 「一句话出一条成片」 |
| 成本对比 | 时间或钱 | 「15 秒广告，8 分钟出片」 |
| 结构预告 | 文章怎么切 | 「编剧 · 摄影 · 剪辑 · 审片」 |
| 悬念缺口 | 留一个没有答案的钩子 | 「这个工位还空着」 |
| 官方数据 | 官方公布的关键数字 | 「官方说单次能读 100 万字」 |
| 门槛提示 | 上手要付的代价 | 「一条命令装完，但要先有 Node」 |
| 对比选择 | 帮读者做决定 | 「要快用这个，要稳用那个」 |
| 现象解读 | 一件刚发生的事 | 「一周之内，两个项目都冲榜了」 |

## 三、两截式：前半截给硬事实，后半截给人味

对标账号「逛逛GitHub」20 条标题实测出来的主导句式（16/20 条带具体数字，20/20 以句号收尾）：

```
[可核对的硬事实] ， [人味评价或悬念] 。
```

- `37K Star 的 GitHub 开源项目开放 AI 网关，10 人团队免费用。`
- `一周就收割 2 万 Star，这个 GitHub 项目把近期爆火的 Jev 模型开源了。`
- `让 AI 帮你操作手机，这个 GitHub 开源项目支持安卓和 iPhone。`

**前半截负责可信，后半截负责想点。** 它的标题汉字数中位是 **17.5 字**，比我们的 20 字上限更短。

**借这个两截结构**（用「，」切成两截，节奏清楚）；
**不借后半截里的夸张词**（堪称一绝、玩疯了、太惊艳了、狠狠收藏）——换成具体结果或事实。

| 学 | 不学 |
| --- | --- |
| 前半截放可核对的数字或事实（Star 数、时间、平台、数量） | 后半截的夸张评价词 |
| 用「，」切成两截，节奏清楚 | 成串的感叹号 |
| 把平台名写进事实里（GitHub / 安卓 / iPhone） | 拿第三方账号名当卖点 |
| 语气平静（它用句号收尾；我们收不收都行，**别靠标点制造情绪**） | 悬念式标题党（"结果万万没想到"） |

## 四、写候选的流程

1. 先写 12 条草稿，不筛，允许烂。
2. 按钩子类型归类，同类只留最好的一条。
3. 做「3 秒测试」：扫一眼能不能说出"给谁看"和"读完能拿到什么"。说不出的删掉。
4. 留 6–8 条，每条标出类型、字数、适合谁。
5. 选定 1 条推荐（写清它靠哪个钩子、与封面主标题怎么分工），其余作为备选。

## 五、写进发布稿的格式

```
> 标题候选：
> ① 数字清单 · 10 个视频行业热门 AI 技能（15 字）· 泛读者
> ② 场景痛点 · 素材一堆剪不动？（9 字）· 自己做短视频的人
> ③ 反常识 · 星标最高的那个，不是技能（13 字）· 技术型读者
> …
> 推荐标题：一个人也能凑齐一个剧组（13 字）｜钩子：身份认同 + 结构预告；与封面「编剧 · 摄影 · 剪辑 · 审片」互补
> 备选标题：① ② ③ ④
> 分享摘要：一句话说清读者能拿到什么（朋友圈与转发卡片用）
```

## 六、标题与封面的分工

- **标题**说清"给谁看"；**封面主标题**说清"能拿到什么"或"文章怎么切"。两者不要写同一句话。
- 封面副标题承接标题没说完的部分（标题讲身份，副标题讲结构）。
- 定稿后连起来念一遍：标题 + 封面第一行，像不像人话。

## 七、自检

- 6–8 条候选，覆盖 4 种以上钩子，没有两条是同一句式的换词。
- 推荐标题 ≤20 字，无标题党词、无极限词，数字与正文一致（`qa.py` 会查这两类词）。
- 推荐标题与封面主标题不重复。
- 删掉最差的 3 条后，剩下的仍然撑得起一次发布。
