# 版权与合规：能写什么、不能写什么、素材怎么标

这份文件管红线。选题、写作、出图都要先过这里，落地时靠 `scripts/qa.py`（违规词、极限词、图片授权）加上 `qa-checklist.md` 的目视项兜底。

## 一、版权：素材只能来自这四类

1. **自己实测产生的**：自己装的、自己跑的、自己截的图。最安全，也最值钱（见 `writing-craft.md` 的证据链）。
2. **公开页面上的事实性信息**：项目名、星标数、许可证、发布时间、README 里的安装命令。照抄并标出处，不发明、不四舍五入。
3. **短引用**：他人文章、帖子、官方公告里的关键句。单处不超过 100 字，全篇引用合计不超过全文的 10%，且必须写清「谁 + 哪个平台」。不整段搬运，也不换词改写别人的稿子。
4. **可商用素材**：图库照片、自己画的图、开源图标。授权要求见第四节。

介绍项目之前先扫一眼它的 `license` 字段：

| 许可证 | 能做什么 | 写文章时的注意 |
| --- | --- | --- |
| MIT / Apache-2.0 / BSD / ISC | 可商用、可改、可再分发 | 转载代码片段时保留版权声明 |
| GPL / AGPL / LGPL | 可介绍，衍生作品有传染性 | 只做介绍与点评，不要大段贴代码 |
| CC BY / CC BY-SA | 可商用，需署名 | 署名 + 许可 + 链接 |
| CC BY-NC / BY-ND | 不可商用或不可改 | 公众号是商业场景，一律不用 |
| 没有 LICENSE | 默认保留全部权利 | 可以介绍，不要复制代码和大段文档 |

几条容易踩的：

- **不搬运整篇 README。** 功能描述用自己的话重述，命令与参数照抄并标出处。
- **不把别人的文章、推文、视频字幕当素材库。** 想引用观点就短引用加署名；想用它的数据就回原始出处核对一遍再写。
- **不搬运付费内容**：付费专栏、知识星球、内部文档、付费课程笔记。
- **不伪造截图。** 界面截图必须来自真实运行的界面；AI 生成的图不能拿来冒充实测截图。
- **截图本身要处理**：裁掉无关部分、打码他人头像昵称与联系方式、不裁掉原作者署名与水印、不给自己加假水印、不拼出误导性画面。

## 二、平台合规：这些一律不写

**题材红线**（公众号、头条、百家号、知乎都查）：政治与涉政解读、民族宗教冲突、暴力色情低俗、赌博彩票、毒品烟草、管制物品；换脸与伪造身份、伪造名人发言；破解、激活、外挂、绕过风控；爬虫绕过反爬、抓取付费或隐私数据；翻墙工具；代写论文、代考、学术造假；替代医生做诊断；生成与传播虚假信息。

**引流红线**：正文与图片都不出现微信号、二维码、外部联系方式，也不写「加群」「关注后领取」，不做诱导分享与集赞。

**隐私红线**：他人真实姓名加单位、手机号、住址、证件号、车牌、订单号、聊天记录截图，一律打码或不写。

**AI 生成内容要标识**（《人工智能生成合成内容标识办法》要求）：

- 图片由 AI 生成：图注或文末写「本图由 AI 生成」。
- 音频、视频同理，文末写一句说明。
- 正文大量借助 AI 起草：文末写「本文由作者整理，部分内容借助 AI 工具辅助」。
- 发布时勾选平台对应的人工智能生成声明选项。
- 本号默认做法是代码排版加可商用照片，通常不涉及图片侧的 AI 标识；当期确实用了 AI 生图，就按上面补标。

**不误导**：

- 星标、调用量、排名都标日期与来源，写明是快照。
- 说「免费」前确认当期确实免费，并补一句「以官网为准」。
- 说「开源」要写清许可证；个人项目不要写成公司产品。
- 效果只写自己实测或作者明确给出的口径，不做推测性承诺。

## 三、违规词与敏感话题

**极限词**（没有权威依据不能用，引用别人的说法时也要改）：国家级、世界级、最高级、最佳、最强、第一、唯一、首个、顶级、极致、绝对、100%、史无前例、绝无仅有、万能、永久、抄底、亏本、血赚、稳赚、翻倍、月入过万。

**替换写法**：

| 想写 | 改成 |
| --- | --- |
| 最强 / 无敌 | 我测下来最稳的一个（给出测试条件） |
| 唯一 | 我找到的少数几个之一 |
| 100% 免费 | 目前免费，以官网为准 |
| 一键搞定 | 一条命令装完，跑完还得自己看一眼结果 |
| 稳赚 / 收益翻倍 | 不写；收益类话题只做信息介绍，不做预测 |
| 史上最强模型 | 官方公布的数据是……（标日期与来源） |

**要加边界的话题**：

- 医疗健康：只做工具介绍，不给诊疗建议，不写「替代医生」。
- 金融投资：不荐股、不预测点位、不承诺收益；涉及此类内容时文末加「本文不构成任何投资建议」。
- 法律税务：不给结论性意见，写明「具体以专业人士与当地法规为准」。
- 教育：不承诺成绩，不代写作业与论文。

## 四、图片素材：只用可商用来源，并且留下记录

**来源优先级**

1. 自己实测的界面截图（首选，最有说服力）。
2. 官方提供、允许使用的品牌素材（少量、指代性使用，不当成视觉识别系统）。
3. 可商用图库：Openverse（筛 CC0 / CC-BY / CC-BY-SA）、Pexels、Unsplash、Pixabay、Wikimedia Commons、NASA 等公共领域机构图库。
4. 自己用代码画的图形（封面与配图的主体一律靠它，见 `visual-recipes.md`）。

**授权要求**

- 禁止 CC BY-NC、CC BY-ND，以及任何「仅限非商业用途」「不可修改」的素材。
- CC0 与公共领域：不强制署名，但仍然记录来源。
- CC BY 与 CC BY-SA：必须署名，图注或文末按下式写：
  `图片：{作者}／{来源平台} · {许可} {版本} · {原始链接}`
  例：`图片：Wendelin Jacober／Flickr · CC0 1.0 · flickr.com/photos/91619724@N04/51917430076`
- Pexels 与 Unsplash 的授权不要求署名，但同样要记录，方便日后被问到出处。

**每期必须建一份记录**：`素材/图库/图片来源.md`（`scripts/stock_photos.py` 会自动写）。没有这份记录，`qa.py` 会直接 FAIL——理由是图库素材必须能追到授权。

## 五、免责声明与署名

稿件结尾的「免责声明」固定三行：

```
- 文章撰写相关信息、数据和素材均整理来源于网络公开信息与本人实测。
- 内容只作为知识分享和讨论，仅供参考，不构成任何专业建议。
- 如有侵权或信息错误请及时联系删除及指正。
```

正文里出现他人素材时就近署名；图库来的图在图注下面跟一行来源小字。文末可以再列一份素材来源，例如：

```
> 素材来源：本图照片来自 Openverse（CC0）；星标与更新时间为 2026-10-10 抓取的 GitHub 快照。
```

## 六、落地顺序

1. 定选题时先自问：这个题材碰不碰红线？碰了就换选题，不要想着绕。
2. 收集素材时，每一条外部素材当场记进 `素材/引用与授权.md`：来源、作者、链接、许可、用在哪。
3. 写稿时短引用加署名；实测与转述分开标注。
4. 出图时只用可商用素材，`stock_photos.py` 落记录。
5. 交稿前跑 `python _工作文件/qa.py 发布稿.md 公众号粘贴版.html`，违规词与授权两项必须 0 FAIL。
6. 发布时勾选平台的 AI 生成声明（当期为 AI 生图或大量 AI 起草时），并保留最后的目视检查。
