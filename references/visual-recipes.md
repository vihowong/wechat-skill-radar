# 出图配方

封面与配图全部**用代码画**：Python 生成 HTML/SVG，再用无头浏览器渲染成 PNG。好处是中文不变形、风格可控、改文案就是改代码，而且能精确控制体积。

基础件在 `scripts/design_kit.py`：色板、发光、箭头、点阵、图标、卡片堆叠、封面骨架、配图画框。

## 一、配色怎么定

> 想每期换一个基调、避免连着几期看起来一样？直接跳到文末「六、一期换一个基调色板」：五套已经配好的色板，以及换色板时不能动的三个账号锚点。

1. **优先向账号自身品牌靠。** 有品牌图时，用取色脚本从图里读出真实色值再设计，别凭印象调色：

   ```python
   from PIL import Image
   im = Image.open("brand.png").convert("RGB")
   for pt in [(40, 40), (300, 300), (900, 120)]:
       print(pt, "#%02X%02X%02X" % im.getpixel(pt))
   ```

   用 `colorsys` 扫一遍区域、按饱和度×明度排序，能顺带把强调色（按钮、图标、小星光）找出来。
2. **一期一个色系。** 深色底 + 一个主色 + 一个点缀色就够；点缀色只用在数字、警示、星光这类小面积元素上。
3. **对比度要够。** 深底上正文用 `#FFFFFF`、次级文案用 `#93A3BC` 一类的灰蓝，别用 40% 透明度的白。

## 二、构图

- **封面**：把标题"压"进行业图形里（集装箱、卡片、K 线、单据），不要做成"上面标题、下面一张图"的三段式。
  - 标题里的关键数字单独换色点亮，和背景里的巨型轮廓数字呼应。
  - 封面自带一条"结构线"（时间轴 / 进度尺 / 流程条），让读者在封面就看出这篇按什么切。
  - 1:1 方图单独排版：徽标、副标题挪到不打架的位置，图形缩小下移，别压到底部信息栏。
- **配图**：一期内的多张图要用**不同骨架**（看板 / 对照 / 管线 / 阶梯 / 漏斗 / 双栏 / 矩阵），统一的是页眉角标、色板和页脚。
- **文字精简**：一张图说一件事；能用图标和箭头说明的，不要写整段文字。最小的字控制在画布宽度的 1% 左右（1080 宽的图画 10–13px 字）。

## 三、体积预算

| 项目 | 建议 |
| --- | --- |
| 单张 16:9 配图 | ≈400KB |
| 七张 16:9 合计 | ≤3MB（微信加载与流量都舒服） |
| 渲染尺寸 | 1080×608（需要更清晰时用 1188×669，但会超预算） |

体积控制手段：点阵放稀（间距 34 而不是 22）、少用大面积渐变、避免把同样的发光叠很多层。先渲染一张量体积，再决定整期尺寸。

## 四、必须避开的坑（都实际踩过）

1. **f-string 里嵌套的字符串不会被替换。** `f"...{svg(txt(0, 0, \"{code}\"))}..."` 这种写法，`{code}` 在替换字段内部属于普通字符串，会原样印出 `{code}`。先把变量算好、拼好，再放进 f-string。
2. **水平或垂直的细线加模糊滤镜会整条消失。** 直线的包围盒高度是 0，`feGaussianBlur` 的滤镜区域随之变成 0。线条发光改用 `style="filter:drop-shadow(0 0 7px 色值)"`。
3. **箭头要记得带定义。** `marker-end="url(#ar0)"` 依赖同一个 SVG 里的 `<marker>`。配图是单独一层 SVG，必须把 `arrow_defs()` 一起传进去，否则箭头不显示（而且不报错）。

## 五、无头渲染

```bash
python scripts/render.py pages/fig1.html 配图/配图1_xxx.png --width 1080 --height 608
python scripts/render.py pages/cover-2x1.html 封面/封面_1276x544.png --width 1276 --height 544
```

- 依赖本机 Chrome 或 Edge，脚本会自动找常见安装路径，也可以用 `--browser` 指定。
- **无头浏览器的窗口有最小宽度（约 500px）**：`--width` 小于 500 时截图会被裁掉右侧，看起来像"版面溢出"，其实是视口限制。要出手机宽度预览，渲染 505 宽再裁中间 375px。
- 渲染完**逐张目视**：徽标与图形是否重叠、标题是否被图形压住、底部元素是否出汗、有没有文字被裁掉。

## 六、一期换一个基调色板

正文版式的颜色是固定的（见 `wechat-layout.md`，`qa.py` 会检查白名单）。**封面与配图的色板每期可以换**——连着几期同一个色系，读者会先腻。下面五套都已经按「深色底 + 一个主色 + 一个小面积点缀色」配好，换个 `use_palette()` 就能用：

| 基调 | 底色渐变两端 | 主色 / 提亮 | 点缀色 |
| --- | --- | --- | --- |
| 墨绿松石（账号默认） | `#060E18 → #245448` | `#3AC98F` / `#5CD971` | `#FF7A59` |
| 深蓝电光 | `#070F1E → #1E3A6E` | `#4FA8FF` / `#7CC2FF` | `#FFD166` |
| 紫青霓虹 | `#0B0A1A → #3A2A64` | `#8B7CF6` / `#A99BFF` | `#3AD8C8` |
| 石墨橙 | `#0E1116 → #4A3126` | `#FF9A3C` / `#FFB865` | `#5CD971` |
| 靛青薄荷 | `#07131A → #173C4A` | `#2FD3C0` / `#5CE6D6` | `#FF7A59` |

```python
# make_pages.py 里换基调：只用改这一行
dk.use_palette(DEEP="#0B0A1A", NAVY="#1B1436", MID="#2A1F53",
               BASE="#3A2A64", BASE_L="#4B3A7A",
               MINT="#8B7CF6", MINT_HI="#A99BFF", MINT_D="#5B4BC4", ORANGE="#3AD8C8")
```

**换色板可以，换风格不行。** 下面三个锚点每期都不动：

1. **账号锚点**：封面右下角始终是「你的skill好友」小字 + 薄荷小圆点；正文配图不出现账号名、二维码、联系方式。
2. **明暗锚点**：一律深色底 + 亮色主色，主色只给标题下划线、图表主线条、数字、强调块；浅底卡片一屏最多出现一次（放"结论"那种）。
3. **信息骨架锚点**：封面固定五件套——eyebrow 小标签、两行大标题、短下划线、一行副标题、右下角账号小字；每期只换**结构图形**和**色板**，这五件套的位置关系不动。

另外两条经验：

- **一期内部必须成体系**：封面和所有配图共用同一套色板与同一种图形语言，别一张一套。
- **对比度优先于好看**：深底上文字用 `#FFFFFF` 与 `#93A3BC`，点缀色只出现在数字、警示、星光这类小面积元素上；出现两个以上大面积高饱和色同屏时，回到明度层级重排。
