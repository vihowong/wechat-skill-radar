# 出图配方

配图分两类：**证据类**（自己实测的截图）和**装饰类**（照片底图 + 代码排版、纯代码图形）。
证据类优先——读者信的是截图，不是好看的封面。
基础件在 `scripts/design_kit.py`：色板、发光、箭头、点阵、图标、卡片堆叠、封面骨架、配图画框、照片底图。

## 一、图片从哪来（按优先级）

1. **自己实测的界面截图**——首选。装着、跑着、出结果的那块屏幕，就是最硬的证据。
2. **可商用图库照片 + 代码排版**——封面和氛围图用。下载走 `stock_photos.py`，自动落授权记录：

   ```bash
   python _工作文件/stock_photos.py search "server room dark" --top 8
   python _工作文件/stock_photos.py pick 3 --used-in 封面
   python _工作文件/stock_photos.py record --file 素材/图库/我的截图.png \
       --source "自测截图" --license "自有" --author "本人" --used-in 配图2
   ```

   默认来源 Openverse（只取 CC0 / 公共领域 / CC-BY / CC-BY-SA）；设了 `PEXELS_API_KEY` 或
   `UNSPLASH_ACCESS_KEY` 可以用另外两家。**禁止 NC / ND 授权**，理由见 `compliance.md`。
3. **纯代码图形**——清单与盘点类文章的主体（看板、对照、管线、阶梯、漏斗、矩阵）。

正文里出现 `素材/图库/` 的图片时，`qa.py` 要求 `素材/图库/图片来源.md` 里能查到它，否则 FAIL。

## 二、实测截图怎么做

这是对标账号（实测向的 AI 技术号）最值得学的一块：它的正文几乎是"一步一图"，读者能跟着截图走完整条流程。

- **一步一图**：每讲一个操作或一个结论，紧跟着就是那一屏。图文比大约 1 张 / 100–150 字，实测与教程类可以到 20–30 张。
- **关键位置画红框**：榜单、表格、数字对不上的地方，用 2–3px 红框圈出来——读者三秒就懂你在说什么。
- **多栏拼图展示工作流**：左边任务列表、右边成品（PPT / Excel / 报告）拼在一起，一张图讲完"从输入到交付"。
- **打码与裁剪**：裁掉无关区域，打码头像、昵称、邮箱、密钥、真实文件名里的个人信息；不要裁掉原作者的署名与水印。
- **截图不要当封面**：封面另做（见下节）；截图用于正文与"结论在哪一屏"的证明。
- 截图类文章的配图比例按内容裁即可，不用统一——在项目根目录放一个 `qa_config.json`：

  ```json
  { "image_ratio": "loose", "max_total_mb": 5 }
  ```

## 三、照片做底怎么排

`design_kit.photo_bg()` 已经把"照片 → 色板色偏 → 左重右轻的压暗"这套做完了，直接传 `photo=` 就行：

```python
dk.cover_page(1276, 544, mark, eyebrow=..., title=..., subtitle=..., chips=[...],
              footer_left="...", photo="../../素材/图库/openverse-01-xxx.jpg", dark=0.66)
dk.figure_page(1080, 608, "F1", "实测 · 数据核对", "标题", art,
               photo="../../素材/图库/xxx.jpg", dark=0.78)
```

- 路径以写出的 HTML 为基准：`_工作文件/pages/` 里的文件引用素材要用 `../../素材/图库/xx.jpg`。
- `dark` 越大越暗：干净的暗调照片 0.6，画面很杂或文字很多时 0.75–0.85。
- **选图标准**：暗调、留白多、没有文字的物体（路牌、屏幕、招牌上的字会和你的标题打架）。
- 压暗是**左重右轻**：左侧接近纯色放标题，右侧留出照片避免整张糊成一块。
- **一张图只用一处照片**，其余交给代码画的图形；同一期所有图共用同一套色板。
- 照片做底的页面**一律输出 JPEG**：同样画面 PNG 约 700KB、JPEG 约 100–250KB。

  ```bash
  python _工作文件/render.py _工作文件/pages/cover-2x1.html 封面/封面_1276x544.jpg \
      --width 1276 --height 544 --quality 86
  ```

## 四、配色怎么定

> 想每期换一个基调、避免连着几期看起来一样？直接跳到文末「八、一期换一个基调色板」：五套已经配好的色板，以及换色板时不能动的三个账号锚点。

1. **优先向账号自身品牌靠。** 有品牌图时，用取色脚本从图里读出真实色值再设计，别凭印象调色：

   ```python
   from PIL import Image
   im = Image.open("brand.png").convert("RGB")
   for pt in [(40, 40), (300, 300), (900, 120)]:
       print(pt, "#%02X%02X%02X" % im.getpixel(pt))
   ```

   用 `colorsys` 扫一遍区域、按饱和度×明度排序，能顺带把强调色（按钮、图标、小星光）找出来。
2. **一期一个色系。** 深色底 + 一个主色 + 一个点缀色就够；点缀色只用在数字、警示、星光这类小面积元素上。
3. **对比度要够。** 深底上正文用 `#FFFFFF`、次级文案用 `#93A3BC` 一类的灰蓝，别用 40% 透明度的白。

## 五、构图

- **封面**：把标题"压"进主题图形里（卡片、流程条、榜单、代码块），不要做成"上面标题、下面一张图"的三段式。
  - 标题里的关键数字单独换色点亮，和背景里的巨型轮廓数字呼应。
  - 封面自带一条"结构线"（时间轴 / 进度尺 / 流程条），让读者在封面就看出这篇按什么切。
  - 1:1 方图单独排版：徽标、副标题挪到不打架的位置，图形缩小下移，别压到底部信息栏。
  - 对标账号的两种封面做法可以借鉴：**极简白底 + 超大标题/大 logo**（适合"某项目突然火了"这类选题），
    以及**产品图标摆进一个工作场景**（适合"两个工具配合"这类选题）。用代码排版复刻前者更容易，后者需要一张干净的场景照。
- **配图**：一期内的多张图要用**不同骨架**（看板 / 对照 / 管线 / 阶梯 / 漏斗 / 双栏 / 矩阵），统一的是页眉角标、色板和页脚。
- **文字精简**：一张图说一件事；能用图标和箭头说明的，不要写整段文字。最小的字控制在画布宽度的 1% 左右（1080 宽的图画 10–13px 字）。

## 六、体积预算

| 项目 | 建议 |
| --- | --- |
| 单张 16:9 代码配图 | ≈400KB（PNG） |
| 单张照片底图 | ≈100–250KB（JPEG，务必用 `--quality` 输出 jpg） |
| 正文配图合计 | ≤3MB；截图很多的实测稿可以放宽到 5MB，在 `qa_config.json` 写 `max_total_mb` |
| 渲染尺寸 | 1080×608（需要更清晰时用 1188×669，但会超预算） |

体积控制手段：照片压暗后再存 JPEG；截图裁到只留要讲的那一块；点阵放稀（间距 34 而不是 22）；少用大面积渐变；别把同样的发光叠很多层。

## 七、必须避开的坑（都实际踩过）

1. **f-string 里嵌套的字符串不会被替换。** `f"...{svg(txt(0, 0, \"{code}\"))}..."` 这种写法，`{code}` 在替换字段内部属于普通字符串，会原样印出 `{code}`。先把变量算好、拼好，再放进 f-string。
2. **水平或垂直的细线加模糊滤镜会整条消失。** 直线的包围盒高度是 0，`feGaussianBlur` 的滤镜区域随之变成 0。线条发光改用 `style="filter:drop-shadow(0 0 7px 色值)"`。
3. **箭头要记得带定义。** `marker-end="url(#ar0)"` 依赖同一个 SVG 里的 `<marker>`。配图是单独一层 SVG，必须把 `arrow_defs()` 一起传进去，否则箭头不显示（而且不报错）。
4. **照片底图别用 PNG 输出。** 同一张封面 PNG 700KB 上下、JPEG 100 多 KB；照片页面输出 `.jpg`。
5. **照片压得不够暗，标题就糊在照片上。** 选暗调照片、把 `dark` 调到 0.75+，别指望靠描边救。

## 八、无头渲染

```bash
python _工作文件/render.py _工作文件/pages/fig1.html 配图/配图1_xxx.png --width 1080 --height 608
python _工作文件/render.py _工作文件/pages/cover-2x1.html 封面/封面_1276x544.jpg --width 1276 --height 544
```

- 依赖本机 Chrome 或 Edge，脚本会自动找常见安装路径，也可以用 `--browser` 指定。
- 输出后缀写 `.jpg` 就会转成 JPEG（需要 Pillow）；照片页面必须这么出。
- **无头浏览器的窗口有最小宽度（约 500px）**：`--width` 小于 500 时截图会被裁掉右侧，看起来像"版面溢出"，其实是视口限制。要出手机宽度预览，渲染 505 宽再裁中间 375px。
- 渲染完**逐张目视**：徽标与图形是否重叠、标题是否被照片里的细节压住、底部元素是否出汗、有没有文字被裁掉。

## 九、一期换一个基调色板

正文版式的颜色是固定的（见 `wechat-layout.md`，`qa.py` 会检查白名单）。**封面与配图的色板每期可以换**——连着几期同一个色系，读者会先腻。下面五套都已经按「深色底 + 一个主色 + 一个小面积点缀色」配好，换个 `use_palette()` 就能用：

| 基调 | 底色渐变两端 | 主色 / 提亮 | 点缀色 |
| --- | --- | --- | --- |
| 墨绿松石（账号默认） | `#060E18 → #245448` | `#3AC98F` / `#5CD971` | `#FF7A59` |
| 深蓝电光 | `#070F1E → #1E3A6E` | `#4FA8FF` / `#7CC2FF` | `#FFD166` |
| 紫青霓虹 | `#0B0A1A → #3A2A64` | `#8B7CF6` / `#A99BFF` | `#3AD8C8` |
| 石墨橙 | `#0E1116 → #4A3126` | `#FF9A3C` / `#FFB865` | `#5CD971` |
| 靛青薄荷 | `#07131A → #173C4A` | `#2FD3C0` / `#5CE6D6` | `#FF7A59` |

```python
# make_pages.py 里换基调：只用改这一行
dk.use_palette(DEEP="#0B0A1A", NAVY="#1B1436", MID="#2A1F53",
               BASE="#3A2A64", BASE_L="#4B3A7A",
               MINT="#8B7CF6", MINT_HI="#A99BFF", MINT_D="#5B4BC4", ORANGE="#3AD8C8")
```

**换色板可以，换风格不行。** 下面三个锚点每期都不动：

1. **账号锚点**：封面右下角始终是「你的skill好友」小字 + 薄荷小圆点；正文配图不出现账号名、二维码、联系方式。
2. **明暗锚点**：一律深色底 + 亮色主色，主色只给标题下划线、图表主线条、数字、强调块；浅底卡片一屏最多出现一次（放"结论"那种）。
3. **信息骨架锚点**：封面固定五件套——eyebrow 小标签、两行大标题、短下划线、一行副标题、右下角账号小字；每期只换**结构图形**、**色板**和**照片**，这五件套的位置关系不动。

另外两条经验：

- **一期内部必须成体系**：封面和所有配图共用同一套色板与同一种图形语言，别一张一套。
- **对比度优先于好看**：深底上文字用 `#FFFFFF` 与 `#93A3BC`，点缀色只出现在数字、警示、星光这类小面积元素上；出现两个以上大面积高饱和色同屏时，回到明度层级重排。
