# 选题：三种形态，多个来源

这份文件管「这一期写什么」。抓取命令与来源清单见 `sources.md`，文章结构见 `editorial-rules.md`。

## 一、先定形态（每期只选一种）

| 形态 | 什么时候用 | 篇内数量 | 主要素材 |
| --- | --- | --- | --- |
| **单项目深挖** | 某个项目、模型、功能或事件正热，或者你自己正好在用 | 1 个主角 + 1–3 个对照 | 自己的实测 + 官方公布数据 + 社区讨论 |
| **主题盘点** | 一个技术方向上同时冒出好几个项目 | 4–8 个 | 抓取清单 + 各家的 README + 至少跑一遍 |
| **清单合集** | 读者是某一类人，需要一组能直接装的技能 | 8–10 个 | 抓取清单 + README + 安装验证 |

判定标准只有一条：**读者扫一眼标题和封面，能说出这篇讲什么、给谁看。** 说不出来就是形态没定住。
形态要写进项目文件夹名和稿件元信息（例：`2026-10-10_单项目_MCP生态实测`）。

三种形态的差别不只是数量：

- 单项目深挖卖的是**实测**，没有三处以上一手证据就别选这个形态。
- 主题盘点卖的是**分布**——谁在做什么、谁还没做、哪条路走得通。
- 清单合集卖的是**省事**——一篇读完知道先装哪个、怎么装、装完干什么。

## 二、主题口径：AI / 科技这条线上的一件事

不再限定"一期一个行业"。主题可以是：

- 一个具体项目、模型、产品或开源库；
- 一个技术方向：Agent、MCP、RAG、语音、视频生成、端侧推理、评测、数据标注……；
- 一类人的需求：做短视频的、做研究的、做跨境电商的、写周报的；
- 一个事件或现象：某榜单变化、某次发布、某个开源项目突然火了。

两条边界：

1. **不脱离人工智能与科技。** 选题、举例、配图元素都在这条线上。
2. **一篇只有一个主角群。** 可以横跨行业，但不要把两个不相干的主题塞进一篇；真要一起写，得有一条能说清的关系（比如"同一类活，两种做法"）。

相邻两期不要重复同一个主题或同一个主角。间隔几期之后再写可以，但必须带新的实测或新的数据。

## 三、来源与热度判断

来源清单、抓取命令、各平台的可用姿势都在 `sources.md`（GitHub、Hacker News、Reddit、X、网页搜索）。
判断"够不够热"时至少凑够两条线，不要只凭一个来源下结论：

| 信号 | 怎么看 |
| --- | --- |
| GitHub | 星标量级 + 近两周星标增速 + 是否仍在更新（`pushed_at`） |
| Hacker News | 分数与评论数，评论里在争什么比分数更有信息 |
| Reddit | 单帖投票与评论数，多个子版在同一周提到同一件事更可信 |
| X | 转发与引用讨论，注意区分作者自荐与真实使用 |
| 媒体 / 博客 | 有人做二次解读，说明它已经出圈 |
| 你自己 | 你刚好在用、被它卡过或救过——这是最硬的热度证据 |

## 四、入选与淘汰（盘点与清单形态用）

按顺序过筛，不符合的直接换下一个：

1. **与本期主题相关**：项目名、描述或 README 能看出它属于这个方向。
2. **实用价值高**：读者装完能在一件真实、反复发生的活上省时间。只能做演示、交不出东西的，降级或不用。
3. **上手简单**：优先「一条命令装完」（●○○），其次「装完选一次配置」（●●○）。要装环境或配密钥的（●●●）一期最多 2–3 个，并且要在字段里写明缺什么。
4. **近期仍活跃**：`pushed_at` 在 45 天内（清单形态）；单项目深挖可以放宽，但要说明它多久没更新了。
5. **未收录过**：跟同一条内容线已发的文章去重（见第五节的 `_已做主题.md`）。
6. **数据抄得到**：项目名、星标、安装命令、功能描述都能从公开页面原文抄到；抄不到的不用。
7. **授权看得懂**：许可证是 MIT / Apache-2.0 / BSD 这类放心引用；GPL 只做介绍；没有 LICENSE 或 CC BY-NC 的，只做点评、不复制内容（见 `compliance.md`）。

## 五、去重与轮换

在内容线根目录维护一份 `_已做主题.md`，一行一期：

```
2026-10-10 | 单项目 | MCP 生态实测 | owner/repo-a
2026-10-14 | 清单 | 给做视频的人的 8 个技能 | owner/repo-b, owner/repo-c, …
```

没有这份文件时，用历史项目文件夹名加各期的 `_工作文件/` 兜底。

同一个项目不重复收录，哪怕星标又涨了；真需要再提，只能在结尾一句话带过。

## 六、凑不够素材怎么办

- **盘点形态：4–6 个就能出。** 结尾写清"这个方向刚起步，现在是入场时间"，把数量少当成信息，而不是缺陷。
- **少于 4 个就换形态。** 改成单项目深挖，或者写成"这个方向为什么还没人做"——用抓取分布当内容，比如某类关键词只搜到个位数项目、最高星标很低。
- **单项目深挖凑不出实测就降级。** 改成资料整理，并在开头告诉读者这是资料整理，不要用推荐的口吻写。
- **永远不要跨主题凑数**，也不要拿非项目类内容（纯清单、数据集、桌面应用）充数——读者看得出。
